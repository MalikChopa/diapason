A cell = keywords, not one more rule: in doubt, the text of `cadrage.md` and `phases.md` prevails. Empty cell or "= default": nothing special.

## Resuming a project built without framing (Reprise d'un projet construit sans cadrage)
The section applies when `docs/FICHE.md` is missing, **with or without** a HANDOFF, and there is code or documents. You **offer** the framing workshop, you do not impose it:
1. Survey read-only what exists (structure, last modification, what runs), changing nothing, and say so ("I saw X in Y").
2. Ask a single button question: **Keep as is** (continue without a sheet; the safeguard, which activates with a sheet, stays inactive) / **Adapt** (short workshop: sheet written from what exists, fields "assumption, to confirm") / **Start from scratch** (full workshop; the existing work is first **copied** to a dated folder, nothing erased or moved) (FR: Garder tel quel / Adapter / Repartir de zéro). Give each option's price to pay. Recommend "Adapt" or "Keep as is" according to what you saw; **never recommend "Start from scratch"**.
3. "Keep" is a legitimate choice (SKILL §2, exception): note it with its date in the project `CLAUDE.md` (FR: "fiche refusée par l'utilisateur le <date>"), then continue with `reprise.md`, without a sheet and without asking again; product decisions met along the way still go to the user (button question). "Adapt" or "Start from scratch": `cadrage.md` (the sheet is a draft, so code is blocked until "Approve").

## Notes
- **Size**: doubt between two cells = the smaller, say so (`phases.md`, Size).
- **Plan**: the preset (`reglages.md`) already sets agents, researches, audits and variants; the column only recalls what changes **per type**.
- **Tools**: only those of the survey (`cadrage.md`) exist. Reading a supplied file or link is allowed; writing into a connected tool needs the user's approval (account, possible money).
- **Level**: the profile's (beginner, intermediate, expert); it changes vocabulary and the number of options, never the decisions that remain the user's.
